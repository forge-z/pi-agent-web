# Header action button sizing

The Tools/Ferramentas and Telegram buttons share the same frame: 120×44 pixels on desktop/tablet and 44×44 pixels on mobile. Their padding, content gap and vertical alignment match. Mobile header actions have an 8-pixel gap so the two touch targets remain visually separate. The change is scoped to those two button IDs and the existing mobile action group; labels, click handlers and the tool visibility pressed-state styling are unchanged.

The focused Chromium geometry check uses the production header HTML, stylesheet, fonts and icons at widths 1280, 1024, 800, 390 and 320, in PT-BR/EN and both tool-toggle states. All 20 cases passed equal dimensions/alignment, matching internal gaps, separated targets and no horizontal page overflow. The local reproducible test and measurements are `/workspace/scratch/header-button-sizing/focused-layout.mjs` and `focused-layout.json`. The existing tool visibility and Telegram UI suites also passed all 16 tests. Full application browser verification also covers the header controls, language changes, Telegram dialog and explicit MCP URL decisions on desktop and mobile, using only local mock services.
